# Beginner's guide

Following is a description of features of three APIs to ensure extension health.

# Creep JS

<b>Creep JS covers the following metrics:</b>

contentWindow (Self) object, CSS System Styles, CSS Computed Styles, HTMLElement, JS Runtime (Math), JS Engine (Console Errors), Emojis (DomRect), DomRect, SVG, Audio, MimeTypes, Canvas (Image, Blob, Paint, Text, Emoji), TextMetrics, WebGL, GPU Params (WebGL Parameters), GPU Model (WebGL Renderer), Fonts, Voices, Screen, Resistance (Known Patterns), Device of Timezone

<b>Creep JS is primarily utilized in the following areas:</b>

JavaScript tampering (prototype lies), Fingerprint lie patterns, Fingerprint extension code, Fingerprint browser privacy settings, Large-scale validation and collecting inconsistencies, Feature detection and fingerprinting new APIs that contain high entropy

# Pixelscan

Pixel scan address fingerprint inconsistencies. Fingerprint is defined as by technical details from your browser and device—like screen resolution, OS, timezone, language, and WebGL—to create a unique ID. Websites can use this ID to recognize or track you across sessions, even without cookies or logins. 

# Cover your Tracks

Cover your tracks works to blend your fingerprint so it's unrecognizable in a detection scan. It's to ensure your signature cannot be singled out.
