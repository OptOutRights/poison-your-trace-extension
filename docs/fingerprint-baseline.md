## Known v1 gaps this baseline is expected to show

These are predicted by the epic (#34) research and should appear in the numbers above. They are the
regressions v2 turns green — recording them here is the point of the harness.

- **worker != window** — the page-world `<script>` override never runs in workers, so
  `WorkerNavigator` / `OffscreenCanvas` leak the real values. Closes in #38.
- **OS contradictions on macOS/Linux hosts** — v1 presents a Windows UA/platform to every user, so on
  a non-Windows host the WebGL renderer, `oscpu`, and fonts betray the real OS. This is a *contradiction*
  a spoof-detector reads as a lie. Closes in #37 (per-OS profiles, report the real OS family).
- **Strict-CSP sites get zero JS protection** — a strict page CSP blocks the inline `<script>`
  injection in Firefox; the harness page has no CSP, so this gap is documented, not measured here.
  Closes in #36 (`world: "MAIN"` injection).
